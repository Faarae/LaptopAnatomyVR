Panduan Pengujian WebAR

1. Pengujian di Smartphone (Android / iPhone)

Pastikan Anda membuka URL dengan HTTPS (misalnya https://192.168.x.x:5173/). Izinkan akses kamera saat diminta browser.

2. Metode Pengujian Dua Layar

Buka file kartu marker di layar laptop Anda (misal marker-cpu.png), lalu hadapkan kamera HP Anda ke layar laptop pada jarak sekitar 20–35 cm.

3. Interaksi Saat Model Muncul

Gunakan tombol + dan − untuk zoom, tombol rotasi untuk memutar, tombol petir ⚡ untuk Auto-Rotate 360°, dan tombol speaker 🔊 untuk narasi suara.
