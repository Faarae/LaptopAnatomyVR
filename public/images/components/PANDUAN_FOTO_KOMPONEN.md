# PANDUAN PENYIMPANAN FOTO FISIK RIIL KOMPONEN (REAL HARDWARE PHOTOS)

Direktori ini (`public/images/components/`) digunakan untuk menyimpan foto fisik asli dari setiap komponen motherboard laptop.

Aplikasi **Laptop Anatomy VR** akan secara otomatis memuat dan menampilkan foto yang Anda letakkan di folder ini pada panel inspektor di halaman **Laptop Explore**:

| Nama File Foto | Komponen Terkait | Pin Number |
| :--- | :--- | :--- |
| `pin-1.jpg` | Slot Ekspansi PCIe x16 (Grafis / dGPU) | Pin #01 |
| `pin-2.jpg` | Header Kipas Pendingin (Fan Headers 12V) | Pin #02 |
| `pin-3.jpg` | Pengendali Penyimpanan (Storage Controller) | Pin #03 |
| `pin-4.jpg` | Slot Memori RAM Utama (SO-DIMM / DIMM) | Pin #04 |
| `pin-5.jpg` | Heatsink Pendingin VRM & Port I/O Belakang | Pin #05 |
| `pin-6.jpg` | Modul Nirkabel Wi-Fi 6E & Slot PCI | Pin #06 |
| `pin-7.jpg` | Bank Saluran Memori DDR Ganda (Channel A/B) | Pin #07 |
| `pin-8.jpg` | Soket Prosesor Tengah (CPU Socket LGA / BGA) | Pin #08 |
| `pin-9.jpg` | Chipset Southbridge (PCH) & Baterai Koin CMOS | Pin #09 |
| `pin-10.jpg` | Slot PCI Ekspansi Sekunder | Pin #10 |

### Format & Resolusi yang Direkomendasikan:
* **Format**: `.jpg`, `.jpeg`, atau `.png`
* **Rasio Gambar**: 16:9 atau 4:3 (Resolusi disarankan: 800x600 px hingga 1920x1080 px)
* **Kualitas**: Foto pencahayaan jelas yang memperlihatkan fisik asli komponen.

Jika file foto belum diunggah, antarmuka akan menampilkan frame placeholder teknis yang elegan secara otomatis.
